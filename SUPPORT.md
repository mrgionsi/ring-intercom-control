# Support

## Questions and Usage Help

Use GitHub Discussions (preferred) or Issues for:

- setup questions
- usage clarifications
- troubleshooting help

## Bug Reports

For bugs, open a GitHub Issue and include:

- environment (OS, Node, Docker version)
- exact steps to reproduce
- expected vs actual result
- logs/error output

## Feature Requests

Open a GitHub Issue with:

- problem statement
- proposed behavior
- alternatives considered
