# Development

## Prerequisites

- Node.js `24.13.0` recommended
- npm `10+`

## Local run

Terminal 1:

```bash
cd backend
npm install
npm run dev
```

Terminal 2:

```bash
cd frontend
npm install
npm run dev
```

## Tests

```bash
cd backend && npm test
cd ../frontend && npm test
```

## Docs site

```bash
cd website
npm install
npm run start
```
